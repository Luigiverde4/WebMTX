    • Emitir

      Publica la cámara y el micrófono de este dispositivo (móvil o portátil).

      Monitoriza cualquier cámara en directo con baja latencia.

      Recupera lo grabado, marca momentos y lánzalos a OBS.

    • Estadísticas

      Tráfico, espectadores y estado de cada cámara en tiempo real.

    • API

      Paths, sesiones, configuración y grabaciones de MediaMTX.
